================================================================================
  CONTEXTO TECNICO CLAVE PARA SIGUIENTE IA
================================================================================

  Stack: Next.js 15 App Router, pnpm, TypeScript, Tailwind, shadcn/ui
  Deploy: Vercel
  Idioma: Spanish (es_AR)

  buildMetadata() en lib/seo.ts: funcion central de metadata - todas las
  paginas la usan. Params: title, description, path, keywords, type
  getBaseUrl(): retorna URL base desde env vars (NEXT_PUBLIC_BASE_URL o
  NEXT_PUBLIC_SITE_URL o fallback "https://vitaespark.com")

  Organization schema en app/layout.tsx: name, url, logo, email,
  sameAs (FB, IG, TikTok), contactPoint

  MarketingPage.tsx: template para landing pages. Props: path, eyebrow,
  title, description, intro[], benefits[], steps[], sections[],
  faqs[], relatedLinks[], exampleImage?, ctaLabel?
  - Genera automaticamente FAQPage + HowTo schemas
  - Usa slugify() para IDs de secciones (h2 con id)

  BlogArticlePage.tsx: template para blog posts. Props: path, title,
  description, intro, sections[], faqs[], relatedLinks[], datePublished?,
  dateModified?
  - Genera Article + FAQPage schemas
  - datePublished visible en page (time element)

  Breadcrumbs.tsx: usa getBaseUrl() para URLs absolutas en schema
  (new URL(item.href, baseUrl).toString())

  TrackedCtaLink.tsx: componente client que trackea clicks con
  @vercel/analytics. Params: href, label, sourcePath, sourceType

  sitemap.ts: publicRoutes array - agregar nuevas rutas aqui manualmente.
  changeFrequency: blog=weekly, others=daily. priority: /=1, blog=0.7, other=0.8

  middleware.ts: redirects. 301 para legales y herramientas duplicadas.
  308 para redirect www. Manage also supabase session cookie.

  Las 3 comparacion pages usan MarketingPage
  Las 3 glossary pages usan BlogArticlePage
  Las 5 sin-experiencia pages usan MarketingPage
